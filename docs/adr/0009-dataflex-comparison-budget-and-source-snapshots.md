# 固定默认对照预算并保存实际源码快照

2026-10-20，grill-with-docs 第三轮已确认。首期对照默认固定优化器更新步数与有效 batch 配置，同时记录实际训练 token 数、策略打分耗时及训练耗时。相同步数不代表相同计算量，比较界面应展示差异；其他预算口径可以明确声明，但其执行约束需另外验证，不能仅凭配置字段宣称已实现。

为支持算法迭代，允许工作区存在未提交修改时导出运行包，但必须保存实际使用的源码快照与内容哈希，同时记录基准 Git commit 和工作区变更状态。仅记录 commit 或本地路径不足以识别实际算法。快照覆盖执行所需源码及自定义组件，排除密钥、模型与缓存；依赖固定和快照打包规则继续讨论。
