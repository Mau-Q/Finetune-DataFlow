# 首版独立部署，向导与画布共用生成流程

首版交付形态为每位使用者独立部署在自己的电脑或服务器上。未来可能演进到共享部署，但当前不引入账号、权限或多用户运行机制；独立部署是首版边界，不是永久排除共享部署。

首版需实际跑通文本 SFT 与视觉语言 SFT 的生成、审核、管理和导出。DPO 暂不纳入首发可用任务，保留后续扩展方向。

常规使用者通过任务向导配置生成，进阶使用者通过已有可视化画布调整流程；两种入口操作同一份流程配置，避免两套生成行为分叉。此前选择包含轻量人工审核工作台；用户随后要求暂不考虑来源修订影响追踪，并表示复核是否需要仍不确定。人工审核不再视为首版已确定的硬要求，以 [ADR-0004](0004-focus-on-finetuning-data-generation.md) 的范围收敛为准。
