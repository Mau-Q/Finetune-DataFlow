# 复用文本完整流程，多模态先交付可配置模板

使用者要求文本 SFT 沿用既有生成 Pipeline，当前按已使用过的 13 算子配置接入，保留生成、评分与筛选逻辑。材料准备继续存在于完整流程内；原先按职责描述的三部分不要求拆成三条独立业务 Pipeline。

多模态选择 MM 基础图片 VQA 作为代表性模板。使用者已明确当前没有可用视觉服务，因此先完成模板、参数和输入输出配置，并准确显示未配置服务和未真实运行的状态；不以真实视觉模型联调为共用框架开发的前置条件，也不为此下载大模型、建设 GPU 环境或安装整套多媒体依赖。以后有现成低成本服务时再做小样本验证。

两条线共用原始材料、Prompt/Schema、任务产物和数据集管理。已有图文数据仍可导入和导出，不因视觉生成服务缺失而不可管理。该决定收敛早期“首版两条线均需实际跑通”的验收要求，以共用框架与文本主线为当前实施重点。
