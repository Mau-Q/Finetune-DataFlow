# 通过 SSH 驱动固定主机，保留可搬运运行包

2026-10-20，用户确认第四轮建议后，明确平台应通过 SSH 连接固定机器训练，并委托代理收敛剩余设计。采用 DataFlow 后端调用系统 SSH/SFTP 的固定主机模式，不建设多集群调度、常驻远程 Agent、消息队列或强制容器平台。运行包是上传、核验、启动的共同交付边界，保留手动导出作为辅助路径。

远程训练由独立进程管理，SSH 断线或网页关闭不等于训练终止；显式停止需确认训练进程组退出。训练主机保存大模型产物，平台同步日志、指标、环境信息与产物清单，模型文件按需下载。环境使用参考依赖、启动前检查与实际版本记录；可搬运包默认包含数据及必要媒体，模型权重采用固定引用或主机路径，大数据引用需要执行前核验。

当前没有 GPU 条件，先以离线契约、合成结果及隔离测试验证流程，真实 SSH/CUDA 训练待资源具备后验收。预留评测记录导入，不在本期实现自动数据修改与再训练闭环。细化设计见 ../dataflex-integration-design.md。
