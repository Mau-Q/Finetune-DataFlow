# 独立源码扩展算法，以实验组组织对照

2026-10-20，grill-with-docs 第二轮已确认。自定义算法在独立 DataFlex 源码中开发，平台绑定组件名称、参数及代码版本，不在首期建设 Python 上传执行或网页代码编辑器。平台需要支持自定义组件参数定义，减少每增加一个算法都修改前端的成本；具体发现和注册协议仍待确定。

对照以实验组组织：共享模型、数据与预算等实验条件，包含指定策略及条件差异的多个实验方案；每份方案可对应多个随机种子或多次运行。相比仅用任务名称归类，这能明确表达对照条件与差异，但预算口径、执行快照和结果匹配规则仍需继续确认。运行包导出不产生真实运行记录。

实施计划阶段用户澄清：以模型训练为主要目的。规范术语改为“训练方案”，允许独立创建和执行；实验组仅在需要比较时使用，不作为普通训练的必填上级。前述实验组组织规则继续适用于对照功能。
