# 面向他人交付数据生成平台，暂缓实现训练反馈闭环

平台目标是交付给其他使用者，覆盖原始材料管理、数据生成和生成数据管理，不能只以个人论文实验脚本作为完成标准。原始材料由用户导入，首版范围不包含材料搜索、下载与订阅采集；视觉方向暂定为视觉语言模型训练数据。

当前优先建立平台框架，暂不实现训练结果驱动的数据更新闭环。框架设计需考虑未来扩展，但尚未确定具体反馈接口、更新策略或自动化程度；“系统提出更新提案、由使用者审核”只是未来可能的选择，不能据此实现自动更新。

交付给其他使用者不等于已决定采用共享部署或多用户架构。部署形态、首版生成任务范围和发布标准仍需继续确认；本决定不改变现有 WebUI 的单用户本地工具约束。
