# 通用文档底层与受约束的生成契约

底层面向通用文档，首批提供论文任务模板。后续目标是服务军事资料 RAG，使用者明确指出这类材料可能不具备论文的规整格式；因此不能把论文结构作为统一材料模型的必需条件，也不能只用规整论文的成功结果证明对目标材料的适用性。具体材料形态、RAG 产物范围及其与 SFT 的关系仍待确认。

使用者可以创建和版本化 Prompt 与 Schema，通过字段映射接入生成、审核和导出；不兼容的配置在运行前拦截。允许扩展字段不代表平台自动具备这些字段的语义审核能力。

数据集草稿允许修改，发布版本冻结；发布后的修改形成新草稿及新版本。已被运行引用的 Prompt、Schema 与来源解析修订也需保持历史可复现，不能随当前编辑覆盖历史运行所用内容。

模型连接兼容远程 API 和使用者自行启动的本地推理服务。平台不承担模型权重下载、本地推理进程启动或 GPU 环境管理。文档解析依赖需独立检查，应用启动成功不能代替解析与生成链路验收。
