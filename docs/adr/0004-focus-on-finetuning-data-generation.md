# 当前只聚焦微调数据生成平台

当前平台为微调服务，范围是原始材料管理、Prompt 与 Schema 管理及解耦、文本和视觉语言 SFT 生成、生成数据集管理与导出。不设计 RAG 知识库产物、RAG 评测集或在线 RAG 系统。生成数据是否进入最终项目、最终是否只交付微调后的模型均未确定；不能据此扩大当前平台职责，也不把训练执行纳入已确定范围。

当前拿不到真实目标材料，解析先复用 DataFlow 现有算子，不开展专门的复杂版面适配，也不制定基于未知材料的验收标准。后续接入时仍需验证所选算子在目标环境中的可用性，复用不代表已验证所有解析格式。

来源修订的影响追踪、依赖样本失效标记与选择性重生成暂缓。用户对复核是否必要仍不确定，人工审核工作台不再作为首版硬要求；自动质量筛选的具体范围同样尚待确定。这不取消已确定的草稿可改、发布版本冻结原则。

本决定收敛 ADR-0002 的人工审核要求及 ADR-0003 的远期 RAG 与材料适配讨论。后续访谈集中于微调数据生成的配置契约、执行和导出，不以未知的最终项目需求驱动实现。
