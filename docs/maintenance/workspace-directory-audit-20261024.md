## 迁移约束

- 训练容器挂载只覆盖旧 smoke 根，不能仅依据宿主的新目录名称判断容器可达性。
- MinerU owner 与 worker 路径依赖解析根，迁移会涉及运行身份。
- 平台活跃 SQLite 位于 node01 本地 Docker 卷，不迁往 NFS。
- 命名美化不修改模型名/revision、G00–G07、任务和样本 ID、框架 checkpoint、自动快照名及历史 JSON 路径。
- 学校 `app/deployment-version.json` 仍是此前部署标记；后来存在局部同步，不能用一个旧提交号概括整棵部署目录。本轮未重新部署或声称两端源码完全一致。
