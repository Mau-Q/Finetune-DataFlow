# 全局交互与数据集筛选验收

2026-10-20。本轮继续使用 DataFlow 的 Vue Fluent 组件和既有数据模型。

## 行为变化

| 范围 | 当前行为 |
| --- | --- |
| 原始数据集 | 名称搜索、实际数据形式筛选、更新时间与名称排序；材料形式与 JSONL 清单编码分开判断 |
| 生成数据集 | 名称、文本/图文、SFT/DPO、发布情况、空/非空样本组合筛选；发布情况依据已有版本，独立于当前草稿状态 |
| 筛选反馈 | 显示匹配数、可移除条件和清空入口；详情返回保留条件，两个列表分别保留各自条件 |
| 原始导入 | 选择按钮不换行、拖入文件或文件夹、相对路径与大小清单、跳过文件反馈、提前检查体积与数量、固定底部操作区 |
| 编辑保护 | Prompt、Schema、样本、材料信息、设置、模型服务、画布和旧配置页离开前确认；刷新窗口由浏览器提示 |
| 样本操作 | 切换和翻页前保护修改；删除前显示目标确认；有未保存修改时禁止发布和字段映射 |
| 连接测试 | 请求失败也释放测试锁，显示错误后可以重试；密钥参数默认使用密码输入 |
| 公共弹窗 | 对话框语义、初始焦点、Tab 循环、Escape、关闭后焦点恢复、窄窗口尺寸约束；多行输入的回车不会触发确认 |
| Fluent 控件 | 按钮支持键盘和禁用语义，输入标签绑定实际输入框；原有下拉组件补上方向键选择 |
| 任务统计 | 使用 completed/queued，兼容 success/pending；未记录执行类型单列；成功率与耗时说明分母，移除推算的数据质量分数 |
| 页面联动 | 统计任务可打开现有任务详情与最终结果；预览页同时支持原始数据集和生成草稿 |
| 错误恢复 | 统计和预览失败显示错误与重试；页面代码加载失败提供重新加载；无样本不能导出预览 |
| 运行边界 | 旧独立 MM 配置明确尚未启用执行，并链接到现有 API 图文 SFT/DPO 流程 |

预览页每次最多加载 100 条，统计与导出仅针对已加载样本。筛选是列表视图操作，不修改数据集，也不会自动发布。

最终本地回归：Core 163 项通过（1 项按 GPU 标记排除），WebUI 405 项及 7 个子测试通过，论文扩展 30 项通过；前端 59 项通过。

本轮验证不证明真实模型 API、MinerU、独立 MM 执行或训练效果。业务数据、备份、浏览器截图和日志均保留本机，不提交公开仓库。

## 数据可视化首次进入卡死修复

同日用户反馈：从侧栏点击数据可视化，尚未加载数据就卡死。此前仅凭独立标签恢复不能排除该页面的更新循环。

根因是 Fluent Combobox 会把新的选中对象经 modelValue/thisValue 回传；封装层没有按实际 key 去重，页面每次渲染又构造新的选项对象，并在收到事件后清空预览状态，引发持续重渲染。修复后，相同 key 不回传，选项列表保持稳定，数据集切换处理也按 key 去重。Chart.js 实例使用 markRaw，离开缓存页面时销毁图表并使未完成预览失效，返回页面时重新创建当前图表。

新增回归用例在修复前捕获到 13 次有界重复事件，修复后为 0；覆盖真正选择变化、预览保留、图表非代理状态与缓存页资源释放。前端总计 63 项测试及生产构建通过。浏览器实际点击侧栏，连续五次往返均响应正常，草稿预览、分布图与缺失值图切换成功，控制台无错误。本次仅修改前端，未重新调用模型或改写业务数据。
