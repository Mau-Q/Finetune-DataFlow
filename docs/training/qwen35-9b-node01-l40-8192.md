# Qwen3.5-9B：学校离线训练与最小跑通方案

更新：2026-10-22（Asia/Shanghai）。**进行中：已有独立训练容器和离线物料准备；完整依赖安装、模型下载、训练结果须以执行记录为准。** DataFlex 源码及其依赖声明保持原样。本方案以先跑通训练为目标，不把正式数据评测或完整平台部署作为前置条件。

## 1. 本次要完成什么

- 模型固定为官方 `Qwen/Qwen3.5-9B`，revision `c202236235762e1c871ad0ccb60c8ee5ba337b9a`。
- node01 单张 L40，纯文本 NF4 4-bit QLoRA、BF16 计算，视觉层冻结。
- 先用构造数据完成两次参数更新、保存 adapter，并重新加载后生成少量 token。
- 再用有效长度接近 4096、8192 的构造数据测显存；单独记录成功、OOM 或其他错误。短训跑通与 8192 容量分别报告。
- 正式 SFT 数据继续由 **Mac 上的现有 DataFlow 平台生成**，导出后上传；本轮不配置校内生成模型服务。
- MinerU 固定 advanced 路线，优先复用学校已有镜像和模型。平台若无阻塞可同时部署；平台或解析接入的阻塞不挡住训练试跑。

## 3. 不改 DataFlex 的依赖组合

现有 DataFlex 的 torchvision≤0.21.0、torchaudio≤2.6.0 限制保留。调整本次环境，采用下列组合：

| 组件 | 版本/依据 |
| --- | --- |
| 基础镜像 | 复用 `hiq/research:cu124-v1` 的镜像内容，新建独立容器；不修改已有推理容器 |
| Python | 镜像中已核实为 3.12.10 |
| torch / torchvision / torchaudio | 2.6.0 / 0.21.0 / 2.6.0；已核实 CUDA runtime 12.4、CXX11 ABI FALSE |
| Triton | 3.2.0，与 torch 2.6.0 配套 |
| Transformers | 5.5.4；固定训练框架排除 5.6.0 |
| PEFT / Accelerate | 0.18.1 / 1.11.0 |
| TRL / datasets / torchdata | 0.24.0 / 4.0.0 / 0.11.0 |
| bitsandbytes | 0.49.2 |
| flash-linear-attention / fla-core | 0.4.2 / 0.4.2；替代原先要求较新 torch 的 0.5.0 |
| causal-conv1d | 1.6.0；发布 wheel 实测 ABI 导入失败，改用原样源码在独立容器内离线编译，匹配现有 Torch/CUDA |
| LLaMA-Factory | 源码 commit `c683e59edd8f893abc5e1403184a1d0644817d2a`，版本 0.9.6.dev0 |
| DataFlex | 主仓库 `repos/dataflex` 原样构建；上游导入 commit `2e2a74dbe90f8b6a1394bdee37518980f1d5958d` |

FLA 0.3.2、0.4.0、0.4.1、0.4.2 的发布元数据及纯 Python wheel 源码已检查；0.4.2 文档要求 PyTorch≥2.5、Triton≥3.0，其工具代码推荐 Triton≥3.2。Qwen3.5 所需的 gated-delta chunk/recurrent 函数、`use_qk_l2norm_in_kernel` 参数和 FusedRMSNormGated 接口均存在。causal-conv1d 1.6.0 的 conv/update 接口也匹配。

这构成候选组合的静态依据，不替代实际导入或 GPU 执行。尤其 FLA recurrent 路径没有 backward；训练应关闭 use_cache 并使用有 backward 的 chunk 路径。短生成可使用 recurrent forward，不能要求它完成不存在的反向传播。

原 Torch 2.7.1/cu128＋FLA 0.5.0 方案与 DataFlex 声明冲突，已退出本次路线。无需放宽 DataFlex 上限，不使用 `--no-deps` 或关闭版本检查来绕过冲突。

## 4. Mac 下载、学校离线安装

学校服务器按离线环境处理，不要求它访问 PyPI、GitHub 或 Hugging Face，也不建立临时联网转发。

1. 在 Mac 下载 Linux x86_64／CPython3.12 依赖；复用基础镜像已满足的版本。DataFlex 和固定 LLaMA-Factory 从原样源码构建纯 Python wheel。
2. Qwen 的 BF16 权重约 19.31 GB，共 4 个分片；同时下载配置、索引、tokenizer、processor 和对话模板。QLoRA 在载入时量化，仍需原始权重。
3. 上传到 node01，核验服务器文件完整后，删除 Mac 本轮下载的临时权重、依赖包和传输压缩包；失败文件保留以便重试。保留小型清单、脚本和日志。
4. 新训练容器使用 `pip --no-index --find-links` 安装；将模型目录只读挂载。移除这个新容器继承的旧 vLLM、句向量、云存储/遥测组件，避免无关包约束污染训练环境。causal-conv1d 在容器内使用现有 CUDA12.4 编译器离线构建。记录 pip check、实际包版本和试训结果。

不改动已有推理/MinerU 容器、宿主 Conda、驱动或其他用户任务。新训练进程单独限制显存使用，运行前刷新 GPU 占用；不能把过去的空闲快照当成当前分配。
