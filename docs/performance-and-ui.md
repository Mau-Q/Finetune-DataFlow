# WebUI 性能与原生组件布局优化

2026-10-20。以 WebUI `8e89be8` 为优化前版本；性能改动为 `adfd56e`，原生组件布局改动为 `f2e0a49`。根仓库当前固定提交见 [组件清单](../locks/components.json)。

## 性能

移除没有页面使用的 PowerEditor 全局注册和样式加载，保留原有 Fluent 组件库。算子详情在单次流程加载期间按名称合并请求，每个节点获得独立副本；加载失败可重试，新流程重新获取元数据。节点加载未完成时重复点击详情不会再次发请求，切换节点仍可发起新请求并忽略旧响应。

| 测量项 | 优化前 | 性能改动后 |
| --- | ---: | ---: |
| HTML 入口 JavaScript（未压缩传输体积） | 2,322,569 bytes | 805,762 bytes |
| HTML 入口 CSS（未压缩传输体积） | 2,564,920 bytes | 1,051,166 bytes |
| 以上两项合计 | 4,887,489 bytes | 1,856,928 bytes（减少约 62%） |
| 打开代表性文本 DPO 的详情请求数 | 11 | 9 |
| 同机浏览器单次 DOMContentLoadedEventEnd | 139.2 ms | 84.2 ms |

体积通过构建输出与浏览器 Resource Timing 交叉核对；布局改动会使具体文件体积有少量变化。DOM 时间是一次本地浏览器采样，受缓存、进程与机器负载影响，不代表稳定的端到端加速比例。常用本地列表接口的热请求约为 1–6 ms，本次没有改动后端服务或声称提升模型生成速度。

## UI

沿用 DataFlow 原有 Fluent 导航、命令栏、按钮和参数控件：

- 工具栏进入独立布局区域，Pipeline 名称与来源正常排版；操作按钮不再漂浮遮挡画布。
- 根据画布可用宽度排列操作分组，窄窗口自动分行；按钮、圆角与强调色统一。
- 空画布提供选择 Pipeline 的入口，直接打开原有列表。
- 详情面板保留原参数控件，长说明进入滚动区；限制面板宽度，增加 Esc 关闭。
- 首次打开模板时按实际存在的输入节点判断加载完成；未绑定输入时也能自动适配完整流程，后续参数更新不反复调整视图。
