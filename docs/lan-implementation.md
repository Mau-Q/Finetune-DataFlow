## P0：权限、存储与迁移设计

现有服务采用模块全局容器、文件注册表和执行器；在同一进程切换全局配置会使并发请求串项目。局域网入口采用认证网关，每个项目使用独立的后台工作进程、注册表、SQLite、媒体和运行目录。工作进程仅监听权限为 0700 的运行目录中的 Unix socket，不暴露 HTTP 端口。历史项目保留原位置和原 ID；新项目使用独立目录。此隔离不构成 Python 执行的操作系统沙箱，开发权限仍属于受信任权限。

网关默认拒绝未纳入路由策略的业务路径。浏览器静态构建可匿名读取；账号接口单独控制；业务路径每次检查会话和当前项目成员。Agent、WebSocket、MCP 在团队模式关闭，不转发旧匿名旁路。评测者仅能访问被分配批次及必要上下文。主机选择器和任意路径接口关闭；开发者上传文件。配置服务凭据需要项目管理权限。

复用：FastAPI/Starlette、httpx 的 Unix socket transport、SQLite backup/短事务、标准库 scrypt。选择 PARTIAL_REUSE：沿用现有数据服务、发布包与锁；新增服务端不透明会话与项目网关。Starlette 的签名 Cookie 会话不能直接满足服务端即时撤销，因此不直接采用它的会话存储。未新增身份框架、外部服务、MCP 或模型依赖。调研范围为本地源码/依赖和官方 Starlette、Python、SQLite 文档；没有检索第三方产品目录。

账号与项目数据库保存用户、单次邀请、会话摘要、成员角色及版本、个人偏好、审计、网关写版本。Cookie 为 HttpOnly/SameSite，HTTPS 部署启用 Secure；写操作校验同源和 CSRF。密码使用随机盐 scrypt，不提供 HTTP 首管理员入口。评测/导出数据与项目的现有 datasets.sqlite3 同事务保存；样本以稳定 ID 与规范 JSON 内容哈希作为修订身份。

迁移不改写既有业务记录。默认项目的历史资源归属由项目工作目录固定；初始化后仅管理员拥有成员资格，其他账号必须授权。无创建者的资源沿用历史导入语义。账号初始化、备份和业务服务启动不执行生成或训练。
