# DPO 本地示例

- `text.jsonl`：3 条文本偏好对。
- `image.jsonl`：3 条图文偏好对。
- `images/shapes.png`：图文样本共享的图片。

每行 JSON 都有 `prompt`、`chosen`、`rejected`；图文数据额外使用 `images`，相对路径从本目录解析。可直接用文本编辑器查看 JSONL，用图片查看器打开 PNG。

启动本地 WebUI 后，在本目录执行：

```sh
python3 import_examples.py
```

可传入不同的本地服务地址作为第一个参数。脚本通过标准 API 上传图片、创建 DPO 草稿并导入文件。重复运行会核对现有数据，不重复创建；已有同名数据内容不同则停止并保留原数据。

导入后，生成数据集列表显示「文本 DPO（示例）」和「图文 DPO（示例）」。草稿保存独立的数据与图片副本，修改这里的文件不会自动改写已经导入的草稿。运行产生的草稿、图片 ID 不写入本目录。
